# Phased site

The landing page, privacy policy and support page for [Phased](https://apps.apple.com/),
served from GitHub Pages.

Plain HTML and CSS - no build step. Open `index.html` in a browser to preview.

- `index.html` - landing page
- `privacy.html` - privacy policy (Privacy Policy URL in App Store Connect)
- `support.html` - support page (Support URL in App Store Connect)
